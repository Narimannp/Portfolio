AreaPlan

Automated floor-area analysis, finished/unfinished classification, building coverage visualization, schedule generation and coordinated sheet composition.

C# / .NETRevit APIWPF / MVVMArea PlansSchedulesSheet Automation

The challenge

Preparing consistent area documentation requires repeated view creation, room identification, area classification, calculations, visualization, schedules and manual sheet alignment. AreaPlan is designed to coordinate these operations through one reproducible workflow.

Tool architecture

UI + UIModelConfiguration, user input, validation, progress and commands
↓
MainProcessorOrchestrates the end-to-end workflow and transactions
↓
_RevitAdaptorViews, parameters, Revit elements, schedules, graphics, sheets and viewport alignment
RoomIdentifierRoom detection, boundaries and finished / unfinished classification
_ProcessAnalyserArea calculations, building coverage, level summaries and result validation
↓
AreaPlanResultPer-level visualizations + building coverage plan + area table + aligned sheets

Automated workflow

01Collect model levels and validate configuration
02Create one area plan per level and a building coverage plan
03Configure required view and area parameters
04Identify rooms and resolve room boundaries
05Classify finished and unfinished areas
06Analyse floor areas and building coverage
07Populate the area-plan schedule / table
08Visualize finished area on each level
09Visualize building coverage
10Place plans and table on sheets
11Position and align viewports and schedule

Implementation notes

Architecture specification, not a claim that the full production tool is implemented. Revit Area elements and Rooms require explicit mapping rules. Area-plan creation requires an AreaScheme and Level. Viewports and schedules have different sheet placement APIs. Separate Revit transactions are coordinated by the processor.
