Project case study

View-Based Design Optimization

Explore building height and position to improve views toward a selected location.

Computational design · Ray-intersection analysis
01 / Problem

The challenge

Building placement and height influence how many units can see a target location, while site and construction-area constraints limit the alternatives.

02 / Goal

The objective

Maximize the number of units with a view toward a selected location.

03 / Approach

Method & contribution

  1. Vary building height and location.
  2. Keep alternatives within site boundaries and construction-area constraints.
  3. Use ray intersections with the target view as the evaluation measure.
  4. Compare generated alternatives through view-analysis geometry.
