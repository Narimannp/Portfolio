Project case study

Automated 2D-to-3D Model Development

Transform 2D drawings into a model with required details, elevations, and views.

Revit · Dynamo · Python
01 / Problem

The challenge

Developing a model from 2D drawing inputs requires repeated interpretation and modeling work, followed by preparation of related views.

02 / Goal

The objective

Automate model development from 2D drawings, including required details, elevations, and views.

03 / Approach

Method & contribution

  1. Use 2D drawings as the workflow input.
  2. Generate model geometry and the required documentation views.
  3. Contribution: Python code and Dynamo workflow development.
